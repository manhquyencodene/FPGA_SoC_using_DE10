# Đồ án môn Lý thuyết - SoC Quartus

## Mô tả
Dự án thiết kế mạch số/FPGA sử dụng Quartus Prime.

## Cấu trúc thư mục
- `src/`: mã nguồn thiết kế (Verilog/VHDL)
- `sim/`: testbench và kịch bản mô phỏng
- `docs/`: tài liệu báo cáo
...

## Hướng dẫn sử dụng
1. Mở project bằng Quartus.
2. Biên dịch thiết kế.
3. Nạp xuống board (nếu có).
